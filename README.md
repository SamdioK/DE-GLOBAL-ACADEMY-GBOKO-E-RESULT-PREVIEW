# DE-GLOBAL-ACADEMY-GBOKO-E-RESULT-PREVIEW

## Mandatory development standards

- [Supabase-Only Persistence Policy](docs/SUPABASE-ONLY-PERSISTENCE-POLICY.md) — all durable application data must use Supabase Database, Supabase Storage, or Supabase Auth as appropriate. Browser storage and device-local persistence are prohibited; browser memory is permitted only for transient interface state.

All modules must pass the policy's release completion checklist before being marked complete.
